# EVIDEX

EVIDEX is an NLP-based research intelligence system.

## Project Purpose
To extract, analyze, and retrieve claims from research papers using an advanced NLP pipeline.

## Setup
1. Use Python 3.11
2. Install requirements: `pip install -r requirements.txt`

## Running Tests
Run `pytest` from the root directory.
